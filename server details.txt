  Required Changes for GPU

  1. Update Environment Variable (Primary Change)

  In your .env or .env.production file, change:

  # From:
  YOLO_DEVICE=cpu

  # To:
  YOLO_DEVICE=cuda        # For single GPU
  # or
  YOLO_DEVICE=cuda:0      # For specific GPU (if multiple GPUs)

  2. Adjust Thread Configuration (Recommended)

  With GPU, you can reduce CPU thread overhead. Update in .env:

  TORCH_THREADS=1         # GPU handles computation, fewer CPU threads needed
  OPENCV_THREADS=2        # Can be reduced
  MP_MAX_WORKERS_CAP=2    # Fewer workers since GPU is the bottleneck, not CPU

  3. Install CUDA-enabled PyTorch (If Not Already)

  # Uninstall CPU-only PyTorch first
  pip uninstall torch torchvision

  # Install CUDA version (adjust cuda version as needed)
  pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118
  # or for CUDA 12.x:
  pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121

  4. Consider Reducing Workers for GPU

  In app/utils/multiprocessing_config.py, the multiprocessing might need adjustment since GPU memory is shared. You may want to:
  - Run with fewer parallel workers (1-2 instead of 4)
  - Or serialize GPU inference while parallelizing other tasks
